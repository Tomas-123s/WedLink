مواصفات الاتجاه المقترح
  • لوحة ليلية خضراء فحمية مع لمسات ذهب معتّق؛ إحساس فيلمي هادئ دون زخرفة كثيفة.
  • عنوان عربي أنيق بخط serif متاح محليًا أو fallback نظامي؛ نص التفاصيل بخط واضح عالي التباين.
  • ترتيب الصفحة: غلاف الاسمين والموعد ← عد تنازلي اختياري ← الموقع والتفاصيل ← صور/وسائط ← RSVP.
  • الهاتف: عمود واحد، أزرار ممتدة، عد تنازلي يلتف دون تمرير أفقي. الحاسوب: غلاف مركزي ومحتوى بعرض مقروء.
  • حركة مقترحة بعد الاعتماد: دخول لطيف للغلاف ولمعة زخرفية مرة واحدة؛ لا حركة مستمرة، مع احترام تقليل الحركة.
  • التباين والمحتوى يعملان دون صور أو حركة؛ الموعد يُعرض حسب منطقة زمنية الحدث.

للمراجعة: اعتمد الاتجاه كما هو، أو اذكر تغييرات اللون أو الخط أو ترتيب الأقسام قبل تنفيذ القالب.
