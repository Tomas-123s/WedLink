# WedLink — Editorial Luxury
## Wedding Invitation Template — Design Brief

**Version:** 1.0  
**Project:** WedLink  
**Template:** Editorial Luxury  
**Design Type:** Premium Cinematic Wedding Invitation  
**Primary Target:** Mobile Users

---

## 1. Design Vision

Create a premium, elegant, romantic and cinematic digital wedding invitation.

The experience should feel like opening a luxury fashion magazine combined with watching a romantic wedding film.

The design must communicate:
- Luxury and elegance.
- Romance and intimacy.
- Modern editorial aesthetics.
- Cinematic visual storytelling.
- Simplicity without looking empty or boring.

Avoid generic wedding invitation templates and overly decorative layouts.

## 2. Brand Identity & Color Palette

**Main palette: Black & Gold**

| Color | Hex | Usage |
|---|---|---|
| Primary Black | #151515 | Main background |
| Secondary Black | #242424 | Secondary sections |
| Champagne Gold | #C6A66B | Highlights and details |
| Warm Ivory | #F1E8D8 | Main typography |

Gold must be used carefully. Avoid excessive gold backgrounds or glowing effects.

## 3. Typography

**Primary Typography: Modern Serif**

Use an elegant modern serif font with distinctive letterforms.

Recommended fonts:
- Cormorant Garamond
- Playfair Display

Use:
- Large elegant typography for the couple's names.
- Clear and readable typography for event information.
- A clean Sans-serif font for small labels, dates and supporting information.

Typography should create a strong editorial hierarchy.

## 4. Hero Section

**Layout: Centered Editorial + Portrait Frame**

This is the most important section.

Design requirements:

1. Deep black background.
2. Small elegant introductory text at the top.
3. Large vertical portrait photograph of the couple, centered.
4. Thin champagne-gold frame around the portrait.
5. Couple's names displayed prominently using Modern Serif.
6. Wedding date underneath the names.
7. Small elegant decorative elements.

The portrait should feel like a luxury editorial photograph, not an ordinary rectangular image.

**Animations:**
- Smooth fade-in for introductory text.
- Subtle image reveal.
- Elegant typography entrance.
- Very subtle floating decorative particles or petals, if visually appropriate.

Do not overuse animations.

## 5. Wedding Countdown & Event Details

Display a premium countdown containing:
- Days.
- Hours.
- Minutes.
- Seconds.

Follow with the event details:
- Wedding date.
- Wedding time.
- Venue name.
- Venue address.
- Google Maps direction link.

Use elegant typography and minimal dividers.

## 6. Our Story / Gallery

Create an editorial photography experience.

Requirements:
- Large wedding photographs.
- Asymmetric image arrangement.
- Different image sizes.
- Elegant spacing.
- Smooth image reveal while scrolling.
- Optional short captions.

The gallery should look like a luxury wedding magazine.

Support both photos and videos according to the selected template configuration.

## 7. Main Wedding Video

Provide a dedicated video section.

Requirements:
- Large cinematic video preview.
- Custom elegant play button.
- Responsive video player.
- Avoid automatic audio playback.
- Maintain the dark visual identity.

## 8. RSVP Section

Create a simple and elegant attendance form.

Fields:
- Guest name (optional).
- Attendance confirmation (Attending / Not Attending).
- Number of companions (when applicable).
- Submit button.

Show a clear success state after submission.

Keep the form visually consistent with the overall design.

## 9. Guest Wishes

Provide a section where guests can send congratulations messages.

Requirements:
- Message input.
- Optional guest name.
- Submit button.
- Elegant message display.
- Clear visual distinction between messages.

## 10. Closing Section

End the experience with:
- A romantic closing sentence.
- Couple's names.
- Wedding date.
- Minimal decorative elements.

The final section should feel memorable, warm and elegant.

## 11. Scrolling & Motion Experience

Use a scroll-based reveal experience.

Important:
- Sections should appear progressively while scrolling.
- Use lightweight transitions.
- Support smooth scrolling.
- Never force the guest to wait for an animation.
- Never lock or hijack scrolling.
- Animations must not reduce accessibility or performance.

## 12. Responsive Design

Mobile is the primary design target.

Mobile:
- Portrait image centered.
- Proper typography scaling.
- Comfortable spacing.
- Full-width responsive sections.
- Touch-friendly controls.
- No horizontal overflow.

Desktop:
- Wider editorial layouts.
- More generous whitespace.
- Controlled image proportions.
- Preserve the same visual identity.

## 13. Technical Design Requirements

- Responsive layout.
- Reusable UI components.
- Smooth but lightweight animations.
- Optimized images and videos.
- Accessible text contrast.
- Reduced-motion support.
- Semantic HTML.
- Consistent spacing and typography system.

## 14. Important Design Restrictions

Do NOT:
- Use generic wedding website layouts.
- Overuse gold.
- Use excessive gradients.
- Use excessive glassmorphism.
- Add unnecessary icons.
- Use too many animation effects.
- Make the design look like an admin dashboard.
- Put all content on the screen at once.

## 15. Final Design Goal

The result must look like a premium, custom-designed wedding experience.

The guest should feel that this invitation was created specifically for this couple, rather than selected from a generic website template.

**Design keywords:**
Editorial Luxury, Modern Serif, Black & Gold, Cinematic, Romantic, Minimal, Premium, Elegant.
