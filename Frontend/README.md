# WedLink Frontend

واجهة WedLink مبنية باستخدام React وTypeScript وVite. نقطة البداية الحالية صفحة عربية بسيطة بتخطيط RTL.

## التشغيل محليًا

من مجلد `Frontend`:

```powershell
npm install
npm run dev
```

يفتح Vite عنوانًا محليًا في المتصفح، غالبًا `http://localhost:5173`.

## إنشاء نسخة بناء

```powershell
npm run build
```

الصفحات والميزات ستُضاف تدريجيًا داخل `src`.
